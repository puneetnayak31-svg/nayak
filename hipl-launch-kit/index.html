HIPL · Launch kit v1.0

Everything you need to go live.

Logos, 21 ready-to-post images, launch copy for every channel, a launch checklist and a setup guide. All on the Sabha identity.

Launch in five steps

From this kit to a live site.

  1. Fill the placeholders

    Speakers, dates, venue, team, contact, website address. Every [BRACKET] goes.

  2. Clear the fact-checks

    Resolve every VERIFY marker against the named edition and translation.

  3. Deploy

    Vercel: root hipl-website, build python3 build.py, output dist.

  4. Connect forms

    Newsletter, questions, RSVPs, pitches. Add spam protection and confirmation emails.

  5. Post

    Set up profiles, then follow the launch-week plan below.
