# HIPL: Hinduism in Public Life

The website, CMS and launch kit for **HIPL**, a modern ideas platform that makes Hindu thought interesting and credible. It covers Dialogues, Interviews, *The First 100 Questions*, the Explorations library, In Person events, Voices, the Weekly Dispatch and the Reading Circle.

- **Website**: about 46 static, mobile-first pages generated by a small Python build. There is no framework and no database.
- **CMS**: a built-in admin at `/admin`. Edit every page's content, run the Inbox for public form submissions, build Explorations pages from interactive blocks, draft pages with AI (Claude), preview and publish.
- **Launch kit**: logos, 23 social images, launch copy and checklists.

## Quick start

```bash
cd hipl-website
python3 tools/check.py        # all checks (Python 3.9+, nothing to install)
python3 cms/server.py         # CMS + site at http://localhost:8800 (password printed in the terminal)
```

Production (Docker + automatic HTTPS on your domain):

```bash
cp deploy/.env.example deploy/.env    # set HIPL_DOMAIN and HIPL_CMS_PASSWORD
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d --build
```

## Repository layout

```

deploy/            docker-compose + Caddy (HTTPS), systemd unit, backup and content-sync scripts
```
